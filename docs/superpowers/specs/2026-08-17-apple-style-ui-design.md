# DeepSeek Harness 控制面板界面改造设计

## 目标

只改善 DeepSeek Harness 控制面板的视觉样式和信息层次，不改变安装、启动、重启、停止、更新、扫描、日志处理或按钮事件逻辑。

## 视觉方向

- 保留 Windows 原生标题栏、窗口按钮和系统行为。
- 使用浅灰白背景，接近 Apple 系统工具的清爽观感。
- 使用白色圆角卡片承载状态信息和日志。
- 使用柔和边框、轻阴影和充足留白，减少默认 WinForms 控件的生硬感。
- 使用蓝色作为主要操作色，绿色表示已安装/正常，灰色表示未运行或禁用。
- 保留现有蓝鲸应用图标。

## 页面结构

1. 顶部状态卡片
   - 安装目录
   - 安装状态
   - 运行状态
   - Harness 版本
   - 每行使用统一左侧图标、标签和右侧值。
   - 状态值使用颜色圆点和文字，不改变现有状态文本。

2. 操作按钮区
   - 保留现有八个按钮及其顺序和事件处理。
   - 使用统一高度、圆角、内边距和图标。
   - “启动”作为蓝色主按钮，其余为白色次按钮。
   - 按钮禁用时使用浅灰背景和低对比度文字。
   - 不改变按钮启用/禁用条件。

3. 日志卡片
   - 保留现有日志文本、滚动和追加逻辑。
   - 使用白色圆角容器、浅边框和更舒适的字体行高。
   - 日志区域占据剩余窗口空间，窗口缩放时跟随调整。

## 实现边界

- 修改范围集中在 `BuildUi`、控件样式初始化和必要的自绘视觉辅助代码。
- 不修改安装目录检测、Node/pnpm 检测、Harness 进程管理、更新逻辑、日志内容或按钮事件方法。
- 不引入新的运行时依赖。
- 继续使用现有 WinForms 和 .NET Framework 编译方式。

## 验收标准

- 窗口标题栏仍为 Windows 原生样式。
- 启动、重启、停止、安装、更新、扫描和打开目录行为与改造前一致。
- 安装、运行、版本状态仍能正确显示，只改变呈现方式。
- 按钮启用/禁用状态仍由现有逻辑控制。
- 窗口缩放时状态卡片、按钮区和日志区域不发生文字重叠。
- 编译通过，桌面程序可正常启动。
